# EcoDash: African Digital Logistics & Infrastructure Simulator

## Project Title
**EcoDash** — Solar-Powered Delivery Simulation

## Project Description
EcoDash is an interactive 2D simulation built with HTML5 Canvas, CSS3, and
Vanilla JavaScript (ES6+). The player controls a solar-powered drone or
electric delivery vehicle transporting essential supplies across an African
environment. The simulation models real-world logistics challenges including
load-shedding, poor road infrastructure, unpredictable weather, and wildlife
crossings. Players must manage battery resources, navigate obstacles, and
complete deliveries within time limits.

This project was developed for the WAS262 Web Animation Scripting module at
STADIO. It demonstrates object-oriented programming, vector mathematics,
collision detection, animation techniques, and responsive interface design.
